# Browse On-Demand Movies and Shows

**On demand** is supplied by JioTV+. Without a connected JioTV+ account the page reports that the extra source must be connected in Settings and lists nothing; Fastway, JioTV, PlayboxTV, Airtel Xstream, Tata Play and VZY are live-TV sources and do not add titles here.

1. Select **On demand** in the sidebar (or the bottom tab bar on a phone).
2. Choose **Home**, **Movies**, **Shows**, **Kids**, or **TV shows**.
3. Browse the rows, or use **Search movies and shows** for a title by name.
4. Use the provider chips, when they appear, to limit the visible titles to one provider.
5. Select a title. For a series, choose a season and then an episode.
6. Select the play item to open the player. Use **Back** to return.

**Expected result:** the selected title's player opens if it is available to the connected account and provider. Catalogues and playback rights vary; an empty section or playback error can reflect account, provider, region, DRM or network limits.

If every section is empty, confirm that JioTV+ is connected and active in **Settings → Provider login**. See [Connect JioTV+](../account-extras/index.md) for the account flow and [Requirements](../getting-started-requirements/index.md) for protected playback.
